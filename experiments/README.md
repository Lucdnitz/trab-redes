# Experimentos

Este diretório receberá o runner headless para a matriz:

- codecs: PCM e Opus;
- perdas: 0%, 1%, 5%, 10% e 20%;
- repetições: 3 por combinação;
- total: 30 execuções.

Os resultados gerados localmente ficam em `experiments/results/`, ignorado pelo Git. Scripts,
configurações e dados de referência reproduzíveis devem permanecer versionados.
